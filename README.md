# Custom Alarm Clock - Annoying Clock (BLARE)
### An alarm clock with a custom PCB, created to be as annoying as possible!

A rectangular prism shaped alarm clock, containing 6 buttons, a display, and a buzzer. The buttons will be used to perform various functions, each meant to be very annoying.
